PORT-WISE EXPLANATION AND RISK
-------------------------------------
Risk: LOW / MEDIUM / HIGH / CRITICAL

[21] FTP (vsftpd 2.3.4)
Does : Uploads/downloads files
Risk : CRITICAL
       Plain-text login. This version
       has a known backdoor
       (CVE-2011-2523).

[22] SSH (OpenSSH 4.7p1)
Does : Encrypted remote login
Risk : MEDIUM
       Secure protocol, but very old
       version. Weak passwords can
       be brute-forced.

[23] Telnet
Does : Old remote terminal access
Risk : HIGH
       No encryption, passwords
       travel in plain text.
       Use SSH instead.

[25] SMTP (Postfix)
Does : Sends and routes email
Risk : MEDIUM
       Can leak valid usernames and
       be abused for spam relay if
       misconfigured.

[53] DNS (BIND 9.4.2)
Does : Converts domain names to IPs
Risk : MEDIUM-HIGH
       Very old version with known
       flaws. Zone transfers may
       leak internal info.

[111] rpcbind
Does : Maps RPC services to ports
Risk : MEDIUM
       Reveals running RPC services
       to attackers.

[139, 445] SMB (Samba)
Does : Windows-style file sharing
Risk : HIGH
       Long history of serious
       vulnerabilities and
       misconfigured shares.

[512] rexec
Does : Remote command execution
Risk : HIGH
       Legacy, unencrypted, weak
       authentication.

[513] rlogin
Does : Remote login
Risk : HIGH
       Trust-based login, plain
       text, easy to abuse.

[514] rsh (tcpwrapped)
Does : Remote shell commands
Risk : HIGH
       Same weaknesses as rexec
       and rlogin.

[1099] Java RMI
Does : Remote Java object registry
Risk : HIGH
       Misconfigured RMI can allow
       remote code execution.

[1524] Bindshell
Does : Nothing legitimate. A
       backdoor shell on a port.
Risk : CRITICAL
       Gives root access without
       any password.

[2049] NFS
Does : Shares folders over network
Risk : HIGH
       Weak export settings can
       expose files to anyone.

[2121] FTP (ProFTPD 1.3.1)
Does : Second FTP server
Risk : HIGH
       Plain-text login and old
       vulnerable version.

[3306] MySQL 5.0.51a
Does : Database server
Risk : HIGH
       Very old version. Should not
       be open to the network. Weak
       root password is common.

[5432] PostgreSQL 8.3.x
Does : Database server
Risk : HIGH
       Outdated, known flaws. Should
       allow trusted hosts only.

[5900] VNC
Does : Remote desktop access
Risk : HIGH
       Old protocol, weak
       authentication, easy to
       guess passwords.

[6000] X11
Does : Linux graphical display
Risk : MEDIUM
       Access denied here (good).
       If open, attackers can see
       screen and keystrokes.

[6667] IRC (UnrealIRCd)

[8009] AJP13 (Apache Jserv)
